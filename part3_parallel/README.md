# Часть 3 — параллельная загрузка и аугментация

Поток-производитель обходит каталог и помещает пути в ограниченную очередь. Потоки-потребители читают RGB-изображения и нормализуют пиксели. Главный поток передаёт массивы процессам для аугментации: исходное изображение, горизонтальное отражение и вариант с шумом.

```powershell
python -m app.performance --path ../data/input/images --output ../data/output/augmented.npy --report ../data/output/performance_report.json --workers 2 --threads 2
```

Команда измеряет последовательную и параллельную обработку и записывает фактические времена в `performance_report.json`. Для небольшого набора накладные расходы на процессы могут сделать параллельный вариант медленнее.
