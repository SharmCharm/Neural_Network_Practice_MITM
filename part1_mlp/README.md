# Часть 1 — многослойный перцептрон

Запустите приложение из каталога `part1_mlp`:

```powershell
python -m app.main
```

CSV-файл должен иметь строку заголовка, числовые признаки и целевой столбец 0/1 последним. Пример находится в `../data/input/classification.csv`. Для бинарной классификации задайте сеть, например `2,4,1`. Скрытые слои используют выбранную функцию `sigmoid` или `relu`; выходной слой использует sigmoid.

Файл весов JSON содержит конфигурацию, веса, смещения и параметры нормализации признаков. Обучение выполняется обратным распространением ошибки с бинарной перекрёстной энтропией и градиентным спуском по пакетам. Для построения графика установите зависимости из корневого `requirements.txt`.
